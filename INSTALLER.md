# SnakeProGo Installer

A cross-platform installer for SnakeProGo that works on Linux, macOS, and Windows.

## Features

- ✅ Downloads binary for your platform (Linux/macOS/Windows)
- ✅ Creates complete directory structure
- ✅ Downloads and installs game assets

## Usage

### Standalone Installer (Recommended)

Run the installer:

```bash
# Basic usage (installs to ~/snakeprogo)
./SnakeProInstaller

# Specify version
./SnakeProInstaller -version v1.0.0

# Windows
SnakeProInstaller.exe
```
